# beijing-shebao-self-employed

非京籍人员通过注册北京个体工商户、以用人单位身份为自己缴纳职工社保（五险一金）的完整办理指引（WorkBuddy Skill 格式）。

## 这是什么

一套沉淀为 AI 技能（Skill）的实操 SOP，覆盖从零开始到长期合规的全流程：

```
阶段 0  材料准备        开网店（微店/淘宝）办经营证明；京通小程序生成居住证确认单
阶段 A  取得单位身份    e 窗通申办个体户执照 → 下载电子营业执照
阶段 B  打通四套系统    社保单位登记 → 社保增员 → 税务报道 → 医保补信息确认
阶段 C  每月缴费        社保费申报缴纳 + 公积金汇缴转账（每月 10–25 日）
阶段 D  季度年度合规    增值税/经营所得 A 表（1/4/7/10 月）→ B 表（3/31）→ 工商年报（6/30）
阶段 E  可选项          公积金开户缴款；工资薪金个税（仅为摇号等需求）
```

## 关键结论（速览）

- 非京籍**不能**以灵活就业身份在京缴职工社保，变通路径是注册个体户、以单位身份给自己增员。
- 2026 年 7 月起按下限缴：社保 **2707.44 元/月**（基数下限 7270 元）+ 公积金约 **127 元/月**（基数下限 2540 元、比例 5%）。
- **全程零跑线下**：居住证确认单用「京通」小程序线上生成（手持拍照、人脸清晰）。
- 高频坑：税务报道必须先做「两证整合个体工商户信息确认」再登录；社保单位登记等 1–2 天共享信息同步可免传要件；无对公账户走「银行短凭证」+ 手机银行（建行搜「实时缴税」）。
