# 非京籍个体户缴纳社保 · 流程蒸馏

> 资料来源：东东's Blog「非京籍个体户缴纳社保」系列十篇 + 两篇补充 + 两篇社保基数调整（https://blog.yasking.org/category/skill）
> 蒸馏日期：2026-11-14 ｜ 原文最新更新：2026-09-15
> 性质：个人实操记录，非官方办事指南。政策与系统入口会变，办理前以各平台当期页面和官方通告为准。

---

## 0. 一句话原理

非京籍在北京**不能以灵活就业身份**缴职工社保（京籍灵活就业也不能单独缴医保，须与养老同时缴）。变通路径是：

**注册个体工商户 → 以「用人单位」身份给自己（经营者）做社保增员 → 由单位名义缴五险一金。**

公司那份和个人那份都由自己出，但身份上算「企业职工」，养老、医保待遇与上班族一致，还能顺带保住摇号资格、缴公积金。**全程可网办**：居住证确认单用「京通」小程序线上生成（2026-11-15 实测修正，原文旧口径为派出所打印，仍可作备选）；（可选）开通工资薪金个税需去税务所。

## 1. 硬门槛与先期准备

| 项 | 要求 |
|---|---|
| 北京市居住证 | 必须有。**线上生成《居住证确认单》：微信/支付宝搜「京通」小程序 → 搜「居住证(卡)申领」→ 进入后点个人中心 → 选「居住证(卡)确认单」→ 按流程指引生成；过程中需手持确认单拍照，人脸要清晰**（北京市公安局官方答复口径 + 用户 2026-11-15 实测）。未申领过居住证：微信搜「北京市居住证」公众号提交申领，约两天后有社区/户籍人员上门办。派出所窗口打印仍可用，作线下备选（2026-02 公告还支持预约「延时办」） |
| 网店经营证明 | 注册个体工商户需先有网店。**微店（原文实测，更简单）**：微店店长版 → 设置 → 店铺设置 → 店铺资料 → 微店开店证明 → 保存「微店平台店铺经营证明」图片。**淘宝（备选，2026-11-15 补充，未实测）**：手机应用商店下载「千牛」APP 或电脑访问千牛卖家中心 → 注册淘宝账号并完成实名认证（身份证 + 人脸，支付宝需同一人实名）→ 创建店铺、选无需许可的类目 → 电脑登录千牛卖家中心 `https://openshop.taobao.com/tools/certificate.htm`（或「店铺 → 店铺信息」页底部「下载开店证明」）→ 生成带平台电子章的 PDF 经营证明，含经营者姓名、身份证号、店铺网址。多平台开店可合并登记，各平台证明都备一份 |
| 电子营业执照 | 支付宝/微信搜「电子营业执照」小程序，登记地选北京，下载执照并改密码。后续多个平台靠它扫码登录 |
| 浏览器 | 社保网上服务平台**用 Chrome 内核**，Firefox 存在兼容性问题（左侧功能列表不显示） |

> 断缴代价（决定是否要办）：小客车摇号要求近五年（含）连续在京缴纳社保、**不能断月**；医保中断 3 个月内续交的次月生效，中断超 3 个月需续交满 6 个月才生效。

## 2. 主线流程（五阶段 · 十步）

### 阶段 0｜材料准备（2026-11-15 新增，对应手把手脚本第 1–2 步）

**① 开网店办经营证明**：微店（原文实测，推荐）或淘宝（备选，未实测）二选一，空店铺即可、无需上传商品。
- 微店：微店店长版 APP → 注册实名 → 创建店铺 → 设置 → 店铺设置 → 店铺资料 → 微店开店证明，保存证明图片。
- 淘宝：千牛 APP → 本人手机号注册（支付宝同人实名）→ 开店认证 → 电脑端千牛卖家中心 `https://openshop.taobao.com/tools/certificate.htm` 下载带电子章的开店证明 PDF（含姓名、身份证号、店铺网址）。

**② 生成《居住证确认单》**：微信/支付宝「京通」小程序 → 搜「居住证(卡)申领」→ 个人中心 → 选「居住证(卡)确认单」→ 按指引生成；**过程中需手持确认单拍照、人脸清晰**。未申领过居住证先走「北京市居住证」公众号申领。派出所窗口打印为线下备选。**全程零跑线下**。

### 阶段 A｜拿到「用人单位」身份

**① 北京 e 窗通提交个体户开办申请**
入口：`https://ect.scjgj.beijing.gov.cn/index` →「个人服务」登录 → 用「北京企业服务 e 窗通」小程序实名认证。

- 先单独做「名称申报」（设立申报 → 个体名称 → 查字号），名称过了再点「立即办理」，避免整体被驳回。经营范围建议选「商贸中心」后缀，覆盖面大。
- 开办问答四个关键选择：使用自主申报名称 **是**；区政务服务中心一站式开办 **是**（营业执照 + 刻章 + 涉税 + 员工五险一金备案 + 银行开户一并流转）；涉税事项/领用发票 **是**；银行开户 **否**（对公户每年几百元，不开不影响缴社保，只是不能自动扣款）。
- 基本信息：申请网店登记 **是**；经营地址必须写成 `平台名：店铺网址` 格式（微店如 `微店：xxx`；淘宝如 `淘宝：https://shopxxxx.taobao.com`——淘宝格式为推断，未实测），否则审核不过；经营形式「个体座商」；资金数额填合理数（无需实缴）；地域「城镇」。
- 经营范围走「经营范围规范表述查询」，**只选「一般事项」、只选一个主营**（烟酒需前置许可、书店需后置许可，跨多品类易被拒）→ 生成结果。
- 五险一金信息按居住证所在区选机构（如昌平）；此处「添加新员工」可跳过，后面单独增员；免费四章全选。
- 提交后状态「待在线签字」：网页端生成文书确认，**但真正的签字要在「北京企业服务 e 窗通」小程序里走「业务确认」→ 自然人/法人业务确认**（不是扫网页的码）。若提示「未开启办理企业登记注册」，回小程序「个人认证」勾选「是否办理登记业务=是」重新认证。
- 状态变「审查中」→ 通常不到一小时营业执照审核通过。领照选 **EMS 寄送**，**不要点「打印领照单」**（点了就得线下自取）；等几小时至一天印章刻好变「可领取」。

**② 下载电子营业执照**（见第 1 节）。后续所有单位登录都靠它。

### 阶段 B｜打通四个政务系统（顺序不能乱）

**③ 社保网上服务平台：单位信息登记**
入口：`https://fuwu.rsj.beijing.gov.cn/zhrs/yltc/yltc-home` →「单位登录」→ 电子营业执照扫码 →「去登记」→「开始申报」。

- **共享信息很可能带不过来，强烈建议等 1–2 天同步成功再办**：同步成功后单位类型、成立日期、登记机关、经营范围、法代姓名等自动代入且不可改，**最大好处是无需上传任何要件**。
- 登记注册地址填居住证地址（与之一致）；再填联系人手机+验证码提交。
- 办结后到「单位中心」下载 *用人单位信息登记_办结通知单.pdf*，审批不通过的原因写在里面。成功后首页左侧才出现完整功能列表。

**④ 社保增员（给自己参保）+ 社保卡（可选）**
同一平台 →「在职职工管理」→「(增减员)社会保险…」→「零星新增」。

- 填自己信息 →「获取共享信息」自动补全；再补劳动用工备案（合同起始日可用营业执照日期、三年固定期限、专业技术岗）。
- 参保信息只显示养老、失业、工伤三项，**医保不在这里，通过后自动协同开通**，办结通知单备注会写「医保部门反馈：成功，无需重复申报」。
- 增员即时办结，无需人工审核。**参保人需以个人身份上传社保卡照片**（「北京人社」公众号 → 微服务 → 个人办理 → 第一二代社保卡照片采集，或 rsj.beijing.gov.cn「我要办社保卡」）；增员后等短信通知再传，太早会报「卡管系统未查询到该人员信息」，照片只能提交一次。
- 实体卡全程约一个月，**不申领不影响缴社保**，期间用电子社保卡即可。
- 时间锚点：如 12/20 完成增员 → 次年 1/10 起可为其缴社保 → 医保 2/1 生效。

**⑤ 北京电子税务局：税务报道（e 窗通提交≠完成）**
入口：`https://etax.beijing.chinatax.gov.cn:8443`

- **先别登录**，先点页面右侧「两证整合个体工商户信息确认」：填统一社会信用代码、负责人身份证、姓名等，点「我要开始办理」。红星必填之外，**黄色框内全部要补**（国标行业（附）、家庭经营信息填经营者本人），否则会卡住。
- 提交得「涉税事项受理系统回执单」，作者实测下午一点多提交、当天下午 6 点出结果，可见 **6 个税种认定**。
- 再用「电子营业执照」方式登录，确认协议、重设密码、签收文书、「我要查询 → 税务文书送达确认 → 同意签订」。**能成功登录即视为报道完成**。
- 若登录报「统一社会信用代码或纳税人识别号错误」，多半就是没做上面那步确认；否则等一两天或致电税务局。
- 可选核验：「纳税人信息查询」能看到纳税人与税种信息；或自然人业务 → 热门服务 →「新办纳税人开业」能看到个体户信息。

**⑥ 医保公共服务平台：补单位信息 + 增员确认**
入口：`https://fw.ybj.beijing.gov.cn/hallEnter/#/Index` → 单位登录 → 北京市统一身份认证平台登录。

- 首次登录必弹「一证通反馈的单位信息不完整」→ 点「立即补填」：单位账号建议填统一社会信用代码，通讯地址填居住证地址，经办人填自己。**提交后会收到含单位账号、经办人账号与密码的短信，务必留存**。
- 「经办人管理 → 权限管理」授权保存；退出后**改用短信里的经办人账号（手机号+密码）登录**，不再用统一身份认证。
- 「网上经办 → 职工信息维护」能查到该人员，即证明社保平台的增员已同步到医保。查不到再用「职工增员申报」手动提交。

### 阶段 C｜每月固定动作（核心）

**⑦ 社保费申报与缴纳**
入口（推荐 Web）：北京电子税务局 →「社保业务」（**2025-08-11 起从「地方特色」移到「我要办税」**）→「申报缴纳」→ 日常申报 / 缴费。客户端（`http://download.bjca.org.cn/download/sbgl.zip`）为等效备选，二选一。

- **每月 10–25 日**自行向税务部门申报缴纳（2024/1/1 起规则）；当月增员，**下月 10 号**才能开始申报。
- 客户端初始化：添加用人单位 → 输入统一社会信用代码 → 去关联。若报「不存在完全匹配的待关联登保信息」，**等 1–2 天等数据同步**即可。客户端密码需到电子税务局「地方特色 → 社保业务 → 社保费客户端密码重置（首次获取）」设置。
- 首次或每年基数调整后要做「年度缴费工资调整」：填低于当年下限的数（如 6000）系统自动按下限计；提交后**必须点一次「申报结果查询」状态才会刷新成全部申报成功**。若日常申报里只有医保记录，回该模块用「按险种申报」把养老/失业/工伤的空基数补成与医保一致。
- 申报：「申报缴纳 → 日常申报」→ 全选记录 → 核对金额 → 提交申报。
- 缴费：无对公账户选「银行短凭证缴费」（Web 端不显示三方协议选项）→ 人工录入姓名/卡号/开户行 → 确认缴费 → **把打印页存成 PDF，记下「银行端查询缴税凭证序号」「纳税人识别码」「税务机关代码」** → 手机银行 APP 缴税入口输入三项完成缴款（**建设银行搜「实时缴税」**，招商、交通银行搜「缴税通」，其他银行在首页搜索「缴税」）。稍后刷新可见「缴费成功」。

> 常见报错「**无有效的汇总预处理信息**」：到「我要办税 → 社保业务 → 年度缴费工资调整」，**生效年度选当前年度**（如 2025）→ 数据初始化成功 →「单个添加」填姓名、身份证、缴费工资 → 勾选提交申报，即解决。

### 阶段 D｜季度 / 年度合规（不做会异常、罚款）

**⑧ 税务申报与工商年报**（均在电子税务局 `https://etax.beijing.chinatax.gov.cn:8443/`，电子营业执照登录）

| 事项 | 周期 / 截止 | 入口 |
|---|---|---|
| 增值税及附加税费（小规模） | 1/4/7/10 月 1–15 日，按季申报 | 「我的待办」或「我要办税 → 税费申报及缴纳」；无销售额直接零申报 |
| 个人所得税经营所得 A 表 | 1/4/7/10 月 | 自然人电子税务局 `https://etax.chinatax.gov.cn`「我要办税」，或扣缴端 |
| 个人所得税经营所得 B 表（年度汇缴） | 每年 3 月 31 日前，一年一次 | 同上；也可在扣缴端导出 B 表 xls |
| 工商年报（年检） | 每年 6 月 30 日前 | 国家企业信用信息公示系统（北京）`https://bj.gsxt.gov.cn/index.html`，电子营业执照扫码登录 → 年度报告填写 → 提交并公示 |

- 零申报也**必须报**；「我要查询 → 一户式查询 → 纳税人信息查询 → 税费种认定信息」可看到 6 个征收项目。
- 扣缴端（自然人电子税务局扣缴端，选「扣缴单位版」）需先「人员信息采集」添加经营者并报送；有营业额时 A 表的「收入总额/成本费用」填**年初至申报期的累计数**，不是当季数。
- 工商年报无数值的填 0，提交后可「预览打印」存 PDF、打印结果告知书，48 小时内公示。

### 阶段 E｜两个可选项

**⑨ 住房公积金（非强制，可整段跳过）**
入口：`https://gjj.beijing.gov.cn/` 网上业务系统 →「登记开户 → 单位登记开户」。e 窗通开办时若已勾选公积金则不必单办。

- 先点右上角「单位信息核验」才会加载可填信息；资金来源「单位自筹」，缴存比例 5%，经办人至少一位，委托收款选填（无对公账户留空）。提交后左侧功能列表可能次日才出现，问题可拨 **12329**（按 0 → 说「转人工」）。
- 增员 → 单笔增员 → 按当年基数下限填写 → 提交增员名单。
- 每月：「公积金 → **缴存 → 汇补缴 → 增减员**」（2026-11-14 实测菜单层级，原文写「公积金 → 汇补缴」缺「缴存」「增减员」两层）确认申报当月缴存人员名单 →「缴款」→ 打印缴款通知单 → **手机银行转账到通知单上的公积金公共账户**（附言/账号由中心识别归属），约 1 小时后状态变「已缴款」。个人缴存基数线上年度内**仅可修改一次**。
- **2026 住房公积金年度（2026-07-01 至 2027-06-30）官方口径**：月缴存基数上限 36348 元、**下限 2540 元**，缴存比例 5%–12%（来源：北京住房公积金管理中心 2026-08-24《关于 2026 住房公积金年度缴存有关问题的的通知》）。按下限 2540、比例 5%：单位 127 元/月；按原文作者口径（单位 5%、个人 0）每月共出 **约 127 元**，若单位与个人均设 5% 则 254 元/月。原文 2024 年度口径（下限 2420、单位 121 元/月、个人 0）已过时，仅作历史对照；「个人比例可否设 0」未实测，以填写页面实际选项为准。公积金单位+个人**都进自己个人账户**，与社保统筹部分不同。

**⑩ 工资薪金个税（仅为摇号等明确需求才办）**

- 线上「补充税（费）种」里没有个人所得税选项，**必须去个体户所属税务所线下办理**，半小时内办完。携带：办税人身份证、营业执照正副本及 A4 黑白复印件、公章、劳动合同（部分区要工资流水，昌平区当时不需要）。
- 前置：办税人先在「电子税务局 APP」注册（人脸识别时手机从下往上照、朝鼻孔易通过）→ 账户中心「添加办税人员」→ 由法人用个人所得税 APP 扫码认证 → 退出后以办税人身份登录 →「企业授权管理 → 待确认授权 → 确认」。
- 开通后在「纳税人信息查询 → 税费种认定信息」即时可见。**开通后每月都要申报，不报会罚款。**
- 申报推荐 Web 端：自然人电子税务局 →「单位办税」→ 综合所得申报 → 正常工资薪金所得（员工信息需重新录入）→ 核对 → 银联缴款。累计预扣法示例：月工资 6000 − 基本减除 5000 − 赡养老人专项附加扣除 950 = 应纳税所得额 50 元 × 3% = **1.50 元/月**。客户端等效，但注意客户端可能默认显示错月份，导致「扣缴单位无有效的税费种认定信息」，关闭重进即可。

| **合计** | | **2707.44 元/月** |

历史对照：2024 年基数下限 6821 → **2540.42 元/月**；2025 年下限 7162 → **2667.27 元/月**（当年 10 月补缴 7、8 月差额共 253.7 元）；2026 年较 2025 增加 **40.17 元/月**。

## 5. 高频坑点速查

1. e 窗通提交只是数据流转，**税务报道、社保单位登记、医保补信息都要各自再做一遍**。
2. 社保单位登记别急着填，等共享信息同步 1–2 天，能免交要件；Firefox 看不到左侧菜单。
3. 电子税务局**先做「两证整合个体工商户信息确认」再登录**，顺序反了会报代码错误。
4. 医保平台首次登录必须补单位信息，之后**改用短信下发的经办人账号**登录，不是统一身份认证。
5. 增员后别急着传社保卡照片/关联客户端，等短信、等数据同步；医保生效还要再等一个月。
6. 社保费「年度缴费工资调整」提交后要点「申报结果查询」刷新状态；只看到医保记录就用「按险种申报」补其余三险。
7. 「无有效的汇总预处理信息」= 当年缴费工资没初始化，选**当前生效年度**重新单个添加人员即可。
8. 无对公账户 → 走「银行短凭证 → 手机银行缴税」链路（建行「实时缴税」/招行、交行「缴税通」），务必保存三个缴款凭证字段；公积金则直接转账到公共账户。
9. 经营范围只选一个「一般事项」主营；网店地址格式必须是 `微店：xxx`。
10. 零申报、工商年报、B 表一个都不能漏，**不申报会经营异常 + 罚款**；开通工资薪金个税后更是每月必报。
11. 摇号资格看连续缴费不能断月，医保断缴超 3 个月有 6 个月等待期。
