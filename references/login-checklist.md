# 登录顺序清单：非京籍个体户缴纳社保

> 按首次办理顺序逐个登录的对照清单，办完一项勾一项。
> 来源为个人实操记录，非官方指南；系统入口与政策会变，办理时以平台当期页面和官方通告为准。
> 完整流程、金额明细、坑点速查见同目录 `full-workflow.md`。

## 从哪里开始

- 前期材料（派出所打印的《居住证确认单》+「微店平台店铺经营证明」图片）已备齐 → 从 **01** 开始
- 营业执照已到手 → 从 **02** 开始
- 社保增员已完成 → 跳到「每月固定入口」
- 四套系统全办完 → 只跑「每月固定入口」+ 年度合规

## 01 · 北京 e 窗通（申领营业执照）

- **网址**：`https://ect.scjgj.beijing.gov.cn/index`
- **登录凭证**：「个人服务」登录，用「北京企业服务 e 窗通」小程序做实名认证
- **操作步骤**：
  1. 先单独做「名称申报」（设立申报 → 个体名称 → 查字号），名称通过后再点「立即办理」
  2. 开办问答：使用自主申报名称 **是**；区政务服务中心一站式开办 **是**；涉税事项/领用发票 **是**；银行开户 **否**（不开对公户不影响缴社保）
  3. 完善经营者信息（人员类型选「个体户」）→ 基本信息：申请网店登记 **是**，经营地址写成 `微店：xxx` 格式，经营形式「个体座商」，资金数额填合理数，地域「城镇」
  4. 经营范围走「经营范围规范表述查询」，只选一个「一般事项」主营 → 生成结果
  5. 五险一金信息按居住证所在区选机构；「添加新员工」可跳过；免费四章全选；填电话与邮编 → 回到首页确认提交
  6. 状态「待在线签字」→ 网页端生成文书确认 → **到「北京企业服务 e 窗通」小程序走「业务确认」→ 自然人/法人业务确认 → 人脸认证并签字**（不是扫网页的码）
  7. 状态「审查中」→ 审核通过后领照选 **EMS 寄送**
- **办结标志**：□ 状态变「可领取」，EMS 收到营业执照与印章
- **注意**：提示「未开启办理企业登记注册」时，回小程序「个人认证」勾选「是否办理登记业务=是」重新认证；**不要点「打印领照单」**，点了要线下自取；过程中随时点「保存」以免进度丢失；节假日提交可能提示「认证失败」，等工作日再交。

## 01b · 电子营业执照小程序（微信 / 支付宝，非网站）

- **登录凭证**：登记地选「北京」→ 下载执照 → 修改密码
- **办结标志**：□ 后续平台点「扫一扫」能正常登录
- **注意**：02、03 的单位登录都依赖它，先办。

## 02 · 北京市社会保险网上服务平台（单位登记 + 增员）

- **网址**：`https://fuwu.rsj.beijing.gov.cn/zhrs/yltc/yltc-home`
- **登录凭证**：「单位登录」→ 电子营业执照小程序扫码
- **操作步骤**：
  1. 「去登记」→「开始申报」，先等 1–2 天让工商共享信息同步成功（同步后免上传任何要件）
  2. 登记注册地址填居住证地址（保持一致）→ 补联系人手机与验证码 → 提交
  3. 「单位中心」下载 *用人单位信息登记_办结通知单.pdf*，不通过原因写在里面
  4. 「在职职工管理」→「(增减员)社会保险…」→「零星新增」→ 填经营者本人信息 →「获取共享信息」→ 补劳动用工备案（合同起始日可用执照日期、三年固定期限、专业技术岗）→ 提交
  5. 参保人以**个人身份**另行上传社保卡照片（见「零散入口」），需等短信通知后再传
- **办结标志**：□ 登录后左侧出现完整功能列表；□ 增员办结通知单备注显示「医保部门反馈：成功，无需重复申报」
- **注意**：用 Chrome 内核，Firefox 不显示左侧列表；增员页面只列养老、失业、工伤三项，医保是自动协同开通的；实体社保卡约一个月，**不申领不影响缴社保**。

## 03 · 北京电子税务局（税务报道；也是每月缴费入口）

- **网址**：`https://etax.beijing.chinatax.gov.cn:8443`
- **登录凭证**：先做「两证整合个体工商户信息确认」，之后用电子营业执照扫码登录
- **操作步骤**：
  1. **先别登录**，点页面右侧「两证整合个体工商户信息确认」→ 填统一社会信用代码、负责人身份证、姓名 →「我要开始办理」
  2. 红星必填之外，**黄色框内全部补齐**（国标行业（附）、家庭经营信息填经营者本人）→ 提交得回执单
  3. 当天出结果后（可见 6 个税种认定）→ 用电子营业执照登录 → 确认协议、重设密码
  4. 「签收文书」→ 点击签收；「我要查询 → 税务文书送达确认」→ 确定 →「同意签订」
  5. 可选核验：「纳税人信息查询」能看到纳税人与税种信息
- **办结标志**：□ 能成功登录即视为报道完成
- **注意**：直接登录报「统一社会信用代码或纳税人识别号错误」，多半是漏了第 1 步；否则等一两天或致电税务局。

## 04 · 北京医保公共服务平台（确认医保已自动增员）

- **网址**：`https://fw.ybj.beijing.gov.cn/hallEnter/#/Index`
- **登录凭证**：首次「单位登录」→「北京市统一身份认证平台登录」→「立即补填」；**之后改用短信下发的经办人账号（手机号 + 密码）登录**
- **操作步骤**：
  1. 补填单位信息（单位账号建议填统一社会信用代码，通讯地址填居住证地址，经办人填自己）→ 提交
  2. 保存短信里的单位账号、经办人账号与密码
  3. 「经办人管理 → 权限管理」授权并保存 → 退出 → 用经办人账号重新登录
  4. 「网上经办 → 职工信息维护」查询该人员
- **办结标志**：□ 能查到该职工；查不到时用左侧「职工增员申报」手动提交
- **注意**：首次必弹「一证通反馈的单位信息不完整」，属正常，补填即可。

## 05 · 自然人电子税务局（经营所得、工资薪金个税）

- **网址**：`https://etax.chinatax.gov.cn`
- **登录凭证**：个人所得税 APP 扫码；单位业务走「单位办税」
- **操作步骤**：经营所得 A 表（1/4/7/10 月）、B 表（3/31 前）在此申报；若已线下开通工资薪金个税，用「单位办税 → 综合所得申报 → 正常工资薪金所得」按月申报缴款
- **办结标志**：□ 「我要查询 → 申报查询」显示申报成功
- **注意**：扣缴端客户端与 Web 等效，二选一，不要重复申报。

## 06 · 国家企业信用信息公示系统（北京）（工商年报）

- **网址**：`https://bj.gsxt.gov.cn/index.html`
- **登录凭证**：右上角手机号注册（需短信验证）→ 手机号 + 密码登录 → 生成二维码后用电子营业执照扫码
- **操作步骤**：企业信息 → 选所在地 →「年度报告填写」→ 如实填写、无数值填 0 →「提交并公示」
- **办结标志**：□ 提示年报提交成功，48 小时内公示；可「预览打印」存 PDF、打印结果告知书
- **注意**：每年 6 月 30 日前完成。

## 07 · 北京住房公积金网（可选，非强制）

- **网址**：`https://gjj.beijing.gov.cn/`
- **登录凭证**：住房公积金网上业务系统
- **操作步骤**：「登记开户 → 单位登记开户」，先点右上角「单位信息核验」加载信息；资金来源「单位自筹」、比例 5%、经办人至少一位、委托收款留空；次日再登录 → 单笔增员 → 每月「缴存 → 汇补缴 → 增减员」（2026-11-14 实测菜单层级）
- **办结标志**：□ 当月缴存状态变「已缴款」
- **注意**：无对公账户时，打印缴款通知单后用手机银行转账到通知单上的公共账户；有问题拨 **12329**（按 0 说「转人工」）。

## 四条顺序红线

1. **e 窗通提交只是数据流转**，02 单位登记、03 税务报道、04 医保补信息都要各自再办一遍，不会自动带过去。
2. **03 必须先做「两证整合个体工商户信息确认」再登录**，顺序反了报「统一社会信用代码或纳税人识别号错误」；黄色框字段别漏填。
3. **02 等 1–2 天共享信息同步**再填，可免上传要件；04 首次补完信息后短信账号密码要存好，之后不再用统一身份认证。
4. **办完不等于能缴**：当月增员要次月 10 日起才能申报，每月 10–25 日缴；医保在缴费次月 1 日生效。

## 每月固定入口（全部办完后只跑这里）

- **社保费**：北京电子税务局 →「**我要办税 → 社保业务**」（2025 年 8 月从「地方特色」迁入）→「**申报缴纳 → 日常申报**」→ 全选核对 → 提交申报 →「缴费」
- **无对公账户缴款**：选「银行短凭证缴费」→ 人工录入姓名/卡号/开户行 → 确认缴费 → 把打印页存 PDF，记下「银行端查询缴税凭证序号」「纳税人识别码」「税务机关代码」→ 手机银行 APP 缴税入口输入三项完成缴款（**建设银行搜「实时缴税」**，招商、交通银行搜「缴税通」，其他银行在首页搜索「缴税」）
- **年度缴费工资调整**：每年基数调整后（或首次申报前）在「我要办税 → 社保业务 → 年度缴费工资调整」做，选**当前生效年度**，填低于当年下限的数即自动按下限计；提交后点一次「申报结果查询」刷新状态
- **公积金**：每月「公积金 → **缴存 → 汇补缴 → 增减员**」确认申报当月缴存人员名单 →「缴款」→ 转账
- **工资薪金个税**（若开通）：每月申报上月，漏报会罚款

## 零散入口

- 社保卡照片：「北京人社」公众号 → 微服务 → 个人办理 → 第一二代社保卡照片采集；或 `https://rsj.beijing.gov.cn/` →「我要办社保卡」→ 个人业务登录
- 邮编查询（e 窗通填写用）：`https://www.youbianku.com/`
- 社保费客户端（Web 的等效备选）：`http://download.bjca.org.cn/download/sbgl.zip`；客户端密码在电子税务局「地方特色 → 社保业务 → 社保费客户端密码重置（首次获取）」设置
